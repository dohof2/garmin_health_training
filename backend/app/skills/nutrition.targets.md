# Nutrition / Targets

Use current targets, user goals, relevant body/activity evidence and uncertainties. Use nutrition_conversation intent=targets with target_request containing only understood/supplied fields: goal (lose_weight, maintain, gain_muscle), target_weight_kg, weight_kg, height_cm, age, equation_sex, activity_factor, rate_kg_week, special_circumstances, calories_kcal. The tool calculates a reviewable proposal using recorded inputs and identifies unresolved fields. Retain answers in update_task and pass the merged request on follow-ups; don't start another intake. The same agent reasons about the response; no nutrition-specific model call is needed. A proposal is not saved targets; browser review/Save applies it. Do not load unrelated full training plans or claim exact needs from sparse evidence.
