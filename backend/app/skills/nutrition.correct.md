# Nutrition / Correct or move a meal

Resolve the exact pending draft or saved meal using retained IDs and revisions. Read nutrition_day to obtain meal IDs, item IDs, quantities, and current revisions. Use nutrition_conversation intent=correct with meal_id, expected_revision, item_id and quantity for a portion correction, or date/meal_type for a meal move. Application code proportionally rescales nutrients and preserves other ingredients. For a food-identity correction, include replacement with its name, grams if changed, and nutrients_per_100g with disclosed assumptions or a verified local food_id from find_food. Use the same item_id; other items and their IDs remain unchanged. Unknown nutrients stay partial. Modify a pending draft in task memory before saving, without touching logged history. Permanent deletion remains in the existing explicit Nutrition UI. Do not log a second meal to implement a correction.
