# Nutrition / Log food

Interpret a consumed-food report, not a food mention in general discussion. The same conversational model identifies foods, quantities and meal/date; no separate nutrition agent or inference call is needed. Use nutrition_conversation intent=log with structured ingredients: name, grams, meal_type, optional nutrients_per_100g and disclosed assumptions. Supply all four nutrient keys when estimating composition; use null for unknown values. Use find_food for source composition when appropriate. Generic composition is an estimate, never a verified package label. Ask a focused portion question when the uncertainty matters, and retain all pending ingredients/date using update_task. For a named package, a likely size may be proposed with assumptions; do not pretend it was measured. Read the logged flag and saved IDs before claiming a save. A ride mention does not require training skills. General discussion does not authorize logging.
