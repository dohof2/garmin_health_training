### 2026-10-25 — Sprint activity

**Observed:** Garmin displayed 52 hours immediately after the activity finished. This is the remaining recovery recommendation at that moment, not a confirmed 52-hour increment caused by this activity alone. The pre-activity Garmin timer is unknown.

**Context reported by the user:** They had not done this kind of activity for a while. The interval since the last comparable sprint session has not yet been established.

**Open details:** Exact activity reference and finish time; app estimate at the same observation time; Garmin timer before starting; sprint count/duration and recorded intensity; Training Effect/exercise load; recent similar-session history; sleep/stress context; perceived effort and soreness; and recovery/next-session experience over the following days. Unknown values stay unknown.

**Possible explanations to revisit:** Unfamiliar sprint demand, residual recovery before the activity, the app's provisional conversion from Training Effect to recovery hours, and differences in available fitness/sleep/stress evidence. A separate user-reported post-sync freshness issue also needs checking before attributing the gap to the recovery model. None is established as the cause.

## Adding future examples

Add one row per activity with both readings taken as close as possible to the same timestamp. Append later observations beneath that example rather than overwriting the initial reading. Record prior recovery, comparable-effort recency and subsequent recovery feedback when available. Identify whether a value came from the user, device, imported data or the app, and retain the app model version when known.

As examples accumulate, compare similar sessions with different familiarity, prior fatigue and recovery context. These examples support investigation and calibration; a discrepancy alone does not establish its cause.
