# Active training and daily coaching — 12 October 2026

Accepted weekly drafts now activate a persistent local program: saved goal/brief, building blocks, horizon, timezone and linked continuation weeks. The Training tab starts with the active plan and upcoming seven days. Opening the app or focusing it reviews the plan; generation fills the visible horizon once per calendar day, within saved availability/volume and constraints. Recovery blocks reduce generated volume. Pausing stops automatic changes; finishing cancels outstanding local sessions and preserves revisions.

Reviews use current readiness (including personal HRV/resting-HR deviations), recorded acute-load bounds, latest sleep, Garmin aerobic/anaerobic effects, recent workload and user effort/soreness/notes. Current low recovery changes imminent demanding generated sessions to easy recovery; adverse feedback reduces demanding upcoming sessions. Fixed commitments and published sessions are held for review instead of silently rewritten. Missing measurements are disclosed. Thresholds and phase lengths are provisional app rules. Recorded training effects indicate stimulus, not measured physiological ceilings; no FTP is inferred.

Users can move a session by date/time or plain requests such as “Move my long ride to today at 18:00”, with revision, overlap and recovery checks. Notes such as “The ride was too hard” attach to the most recent matching past session; the session editor offers explicit targeting, effort, soreness and linked activity. Assistant tools read the active plan and propose reviewed schedule/feedback changes with a Save button; they do not directly write.

“I have 60 minutes today” uses today’s active session if available, preserves rest days and checks recovery. Without a plan it offers a bounded session using saved preferences/recent workload. A small time/sport form offers the same capability in Training. Recommendations do not implicitly save or replace a session. Cycling/running suggestions include exact-duration warmup/main/cooldown; strength requires equipment/movement preferences.

Recent training mix uses Garmin primary-benefit labels over 7–42 days (default 14), distinguishing base/endurance, tempo/threshold and short-hard-effort exposure. At least three activities and 60% known labels are required to identify possible gaps. Poor coverage is not interpreted as missing training. A gap may guide a no-plan session when saved experience and current recovery permit; the active plan takes priority. Short-hard-effort labels do not certify sprint intervals.

Validation: 389 backend tests passed; frontend typecheck/production build and whitespace checks passed. Nineteen dedicated active-training tests cover persistence, repeated opens, week continuation, pause/expiry, replacing plans, stale move protection, natural feedback, read-only assistant proposals, available-time sessions, low recovery and label-based mix coverage. Isolated browser checks using invented data verified the top panel, saved blocks, 60-minute recommendation and feedback-triggered reductions. No model call or personal-data upload was made. The real database contained no existing plans; none was invented or activated for the user.

UI follow-ups: More details now replaces the sample-count/source/timezone sentence inside an expanded activity summary. Remove activity stays at the bottom of More details. Assistant activity evidence is plain text. Stream plots use variable labels/colors; Y-axis margins use half a plotted standard deviation on either side, with a constant-series fallback.

Limits: missing historical Garmin benefit labels limit mix assessment. Opening/focus reviews are local deterministic rules, not a live model consultation. Model use of the new tools is instructed but has not been retested through the connected account. No Garmin workout publishing was added.

Follow-ups: explicit rest and gentle recovery-ride suggestions; Upcoming events list populated by coach descriptions with a manual correction editor; distance/ascent/race fields feed event preparation and recovery, with duration estimates only from at least three comparable recorded activities. Non-race wording is preserved. Pull-up and dip bars are accepted equipment options. The requested broader agent-first layout remains a design direction; the separate goal form has not yet been removed.
