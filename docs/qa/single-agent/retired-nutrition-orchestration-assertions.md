# Replaced orchestration assertions

The old role router, keyword intent interceptors, canned replies, separate provider stream loops, and workflow switch were removed. Their implementation-specific assertions are replaced by `backend/tests/test_skill_agent.py`, which tests the shared model loop, skill isolation, continuation, structured edits, receipts, channel permissions and resumable planning. Domain fixtures and tests not dependent on those removed orchestration mechanisms remain. The fifty prescription preview/save cases now call the domain service directly.
